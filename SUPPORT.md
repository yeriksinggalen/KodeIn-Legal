Gunakan [halaman penghapusan akun/data](https://yeriksinggalen.github.io/KodeIn-Legal/account-deletion.html) atau email yang sama dengan subjek **KodeIn privacy request**. Permintaan ditangani secara privat; GitHub Issues bukan tempat untuk informasi akun atau peserta. / Use the [account/data deletion page](https://yeriksinggalen.github.io/KodeIn-Legal/account-deletion.html) or the same email with subject **KodeIn privacy request**. Requests are handled privately; GitHub Issues should not contain account or participant information.

## Masalah keamanan / Security concerns

Email secara privat dengan subjek **KodeIn security report**. Jelaskan dampak dan langkah reproduksi dengan data sintetis. Jangan publikasikan kerentanan yang melibatkan data pengguna atau kredensial. / Email privately using **KodeIn security report**, describing impact and reproduction with synthetic data. Do not publicly disclose vulnerabilities exposing user data or credentials.
